# ♠️ Blackjack

Un pequeño juego de **Blackjack para navegador**, en el que puedes
enfrentarte a la banca, intentar acercarte a 21 puntos y poner a prueba
tu suerte.

## 🎮 Cómo jugar

1.  Introduce tu nombre para comenzar.
2.  Recibirás dos cartas y la banca empezará con una carta visible y
    otra oculta.
3.  Pulsa **Pedir** para recibir otra carta.
4.  Pulsa **Plantarse** cuando quieras terminar tu turno. Entonces
    jugará la banca.
5.  Gana quien consiga acercarse más a 21 sin pasarse.

Si superas los 21 puntos, pierdes la ronda.

## 🃏 Valores de las cartas

  Carta                   Valor
  ------------------ ----------
  Cartas numéricas     Su valor
  J                          11
  Q                          12
  K                          13
  As                          1

La banca pide cartas mientras tenga 17 puntos o menos.

## ✨ Características

-   Reparto de cartas con animaciones.
-   Turnos diferenciados entre jugador y banca.
-   Detección de cartas repetidas durante una partida.
-   Recuento automático de puntos.
-   Mensajes de estado y anuncio del ganador.
-   Posibilidad de reiniciar y volver a jugar.

## 🚀 Ejecutar el proyecto

Abre el archivo `index.html` en tu navegador. No se necesita un proceso
de compilación para ejecutar la versión del juego.
